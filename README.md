# 中文

**Ninja 2.0** 是一套基于 **Mihomo / Clash-Mihomo** 与 **Leaf** 深度修改的网络核心与多平台客户端方案。

它并不是简单封装公版内核，而是围绕 **协议实现、握手流程、握手时序、身份验证、订阅分发、流量特征与隧道传输** 持续进行定向优化。

## ✨ 主要特性

* **深度修改 Ninja Core**
  基于 Mihomo 与 Leaf 持续重构和优化，而非简单二次封装。

* **协议与流量特征优化**
  调整部分公版实现中较固定的通信行为与运行特征。

* **握手与时序优化**
  对连接建立流程、交互顺序以及部分握手时序进行重新设计。

* **Ninja Tunnel Layer**
  Ninja 2.0 引入独立隧道封装层：

```text
Ninja Client
     ↓
Ninja Core
     ↓
Tunnel Layer
     ↓
Network Transport
```

隧道参数可以根据实际部署需求调整，包括部分传输、连接、Session 与时序参数，使整体网络行为具备更高的可配置性。

* **加密与混淆订阅**
  支持 Ninja 专用订阅内容加密与混淆，降低传统明文订阅直接暴露完整节点信息的风险。

* **多层身份验证**
  在客户端、订阅、协议及服务端之间提供更完整的访问控制体系。

# English

**Ninja 2.0** is a deeply customized networking core and multi-platform client solution built on top of **Mihomo / Clash-Mihomo** and **Leaf**.

Rather than simply wrapping a public upstream core, Ninja introduces targeted modifications across the **protocol stack, handshake flow, timing behavior, authentication, subscription delivery, traffic characteristics, and tunnel transport layer**.

## ✨ Key Features

* **Deeply Customized Ninja Core**
  Continuously modified from Mihomo and Leaf for real-world deployment.

* **Protocol & Traffic Profile Optimization**
  Selected behaviors commonly shared by standard public implementations are redesigned and independently maintained.

* **Handshake & Timing Optimization**
  Connection establishment, sequencing, and selected timing behavior are further optimized.

* **Ninja Tunnel Layer**

```text
Ninja Client
     ↓
Ninja Core
     ↓
Tunnel Layer
     ↓
Network Transport
```

Selected tunnel parameters, session behavior, transport settings, and timing profiles can be customized according to deployment requirements.

* **Encrypted & Obfuscated Subscription Delivery**
  Reduces unnecessary exposure of complete node configuration through conventional plaintext subscriptions.

* **Multi-Layer Authentication**
  Provides additional access-control capabilities across clients, subscriptions, protocols, and server infrastructure.
